# Kavindhya Gothmini - Portfolio

A professional personal portfolio website built with Laravel, showcasing my software engineering background, technical skills, projects, education, certifications, and professional experience.

## About

This portfolio was developed to present my professional profile and software engineering work in a structured and modern web application.

It includes both a public-facing portfolio and an administrative management system for maintaining portfolio content.

## Features

### Public Portfolio

- Home
- About Me
- Technical Skills
- Projects
- Professional Experience
- Education
- Certifications
- CV
- Articles / Learning Notes
- Contact

### Admin Dashboard

- Dashboard
- Profile Management
- Project Management
- Article Management
- Skills Management
- Experience Management
- Education Management
- Certification Management
- Contact Message Management

## Technologies

- PHP
- Laravel
- MySQL
- HTML5
- CSS3
- JavaScript
- Bootstrap
- Vite
- Blade Templates

## Project Structure

The application follows the Laravel MVC architecture:

- Models - Database and application data
- Controllers - Application logic
- Routes - Application URL routing
- Blade Views - User interface
- Migrations - Database structure
- Admin Panel - Portfolio content management

## Database

The project uses MySQL for storing portfolio information such as:

- Profile information
- Projects
- Skills
- Experience
- Education
- Certifications
- Articles
- Contact messages
