## 💻 Run Locally

To run the portfolio on your local computer:

1. Clone the repository:

   ```bash
   git clone https://github.com/kavindhya-gothmini/kavindhya-portfolio.git
   ```

2. Move the project into your local development environment.

3. Install the PHP dependencies:

   ```bash
   composer install
   ```

4. Create a `.env` file based on `.env.example` and configure the required environment settings.

5. Generate the application key:

   ```bash
   php artisan key:generate
   ```

6. Configure your local MySQL database in the `.env` file.

7. Run database migrations if required:

   ```bash
   php artisan migrate
   ```

8. Start the Laravel development server:

   ```bash
   php artisan serve
   ```

9. Open the local URL:

   `http://127.0.0.1:8000`

**Note:** The local setup may require additional configuration depending on the repository's current files and database requirements.
